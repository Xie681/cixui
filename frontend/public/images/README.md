# 图片资源说明

## 数字绣娘IP形象

请将您设计的数字绣娘3D卡通形象图片命名为 `digital-embroiderer-ip.png` 并放置在此目录下。

### 图片要求：
- 文件名：`digital-embroiderer-ip.png`
- 格式：PNG（支持透明背景）
- 推荐尺寸：400x600px 或更大（保持宽高比）
- 背景：透明或白色

### 使用位置：
- 首页右下角（Home.vue）
- 定制下单流程页面右下角（CustomOrderFlow.vue）

### 动画效果：
- 自动浮动动画
- 每5-6秒自动挥手
- 点击可触发挥手动画
- 发光效果
- 对话气泡（可选）

如果图片不存在，组件会自动使用SVG备用形象。
