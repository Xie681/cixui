# Hero区域图片说明

## 图片位置

请将以下两张图片放置在 `frontend/public/images/hero/` 目录下：

### 1. 原图设计
- **文件名**: `original-design.jpg`
- **说明**: P2图片 - 原始数字设计图（花卉图案的平面设计图）
- **路径**: `frontend/public/images/hero/original-design.jpg`

### 2. AI刺绣结果
- **文件名**: `ai-embroidery-result.jpg`
- **说明**: P3图片 - AI处理后的刺绣结果图（展示实际刺绣效果）
- **路径**: `frontend/public/images/hero/ai-embroidery-result.jpg`

## 图片要求

- **格式**: JPG 或 PNG
- **建议尺寸**: 1200x800px 或更大（保持16:9或类似比例）
- **文件大小**: 建议小于2MB，以优化加载速度

## 使用说明

这两张图片会在首页Hero区域的"所见即所绣"对比展示中使用：
- 左侧显示原图设计
- 右侧显示AI刺绣结果
- 中间有AI转换图标和流程动画

如果图片未正确加载，浏览器控制台会显示警告信息。
