## 二、核心业务模块设计

### 2.1 用户端模块

#### 模块1：用户认证与账号管理
- 注册：手机号/邮箱 + 验证码
- 登录：密码登录、验证码登录、三方登录（微信/QQ/支付宝）
- 个人中心：基本信息、收货地址、历史订单
- JWT Token刷新机制

#### 模块2：定制下单

**A. 图像定制流程**
1. 上传图片 → 文件校验（格式/大小）
2. 选择绣制风格（苏绣/湘绣/蜀绣/粤绣）
3. 调用AI服务生成针法数据
4. 可交互预览（Satin/Fill/Run针法、颜色层数）
5. 尺寸/面料/线材选择
6. 实时报价 → 下单支付

**B. 文字定制流程**
1. 输入文字/上传手写图片
2. 选择字体库
3. 走针预览
4. 多字排版模板（校徽/云肩等）
5. 尺寸/面料/线材选择 → 下单

**C. 花样商城**
1. 模板浏览（分类、搜索、筛选）
2. 模板详情预览
3. 二次编辑（调色/缩放/加字）
4. 加入购物车/直接下单

#### 模块3：报价引擎

**计算公式：**
```
总价 = 基础价 + 针数费 + 色数费 + 面料费 + 线材费 + 急单加价
```

**参数：**
- 针数（stitch_count）
- 色数（color_count）
- 剪线次数（trim_count）
- 面料类型（fabric_type）
- 线材类型（thread_type）
- 尺寸（width × height）
- 急单系数（urgent_factor）

#### 模块4：生产追踪

**订单状态流：**
```
待支付 → 设计中 → 打样中 → 复审中 → 排产中 → 绣制中 → 质检中 → 待发货 → 已发货 → 已完成
```

**实时推送：**
- WebSocket推送状态变更
- 设备进度条（已绣针数/总针数）
- 预计完成时间

#### 模块5：售后管理
- 申请售后（退款/返修）
- 工单提交（上传问题图片）
- 客服沟通
- 退款/换货流程

#### 模块1：工作台

- 优先级排序（紧急/普通）
- 截止时间提醒
- 快速操作入口

#### 模块2：AI可视化精修

**功能：**
- 接收AI生成的初版设计
- 分区显示（不同针法区域）
- 走针叠层可视化
- 参数侧栏调整：
  - 针法类型（Satin/Fill/Run/Motif）
  - 密度（density）
  - 角度场（angle）
  - 连接/剪线优化
  - 换色顺序调整
- 智能建议：减剪线/合并色层/路径重排
- 所见即所得实时渲染

#### 模块3：三库管理

**A. 工艺知识库**
- 针法模板（预设参数）
- 图元默认策略（文字/边框/填充）
- 质检规程标准

**B. 设备特征库**
- 设备品牌/机型
- 绣框尺寸
- 最高转速
- 联机协议
- 支持文件格式（DST/PES/JEF等）

**C. 材料数据库**
- 面料库（名称/缩率曲线/适用场景）
- 线卡/色卡（品牌/色号/RGB值）
- 推荐张力/速度值

#### 模块4：产线联动
- 选择设备/工厂
- 下发花样文件
- 并发队列管理
- 设备状态监控（在线/离线/工作中）
- 实时进度查看

#### 模块5：质检与追溯
- 质检表单（标准项/缺陷类型）
- 拍照上传
- 不良品标记
- 返修流程
- 全流程追溯（订单→设计→生产→质检）

CREATE TABLE `user` (
  `id` BIGINT PRIMARY KEY AUTO_INCREMENT,
  `phone` VARCHAR(20) UNIQUE COMMENT '手机号',
  `email` VARCHAR(100) UNIQUE COMMENT '邮箱',

CREATE TABLE `user_oauth` (

### 6.2 报价计算逻辑

```java
// 伪代码
public BigDecimal calculatePrice(OrderDetail detail) {
    // 基础价
    BigDecimal basePrice = getBasePrice(detail.getType());

    // 针数费（每1000针）
    BigDecimal stitchFee = new BigDecimal(detail.getStitchCount())
        .divide(new BigDecimal(1000))
        .multiply(new BigDecimal("2.0"));

    // 色数费
    BigDecimal colorFee = new BigDecimal(detail.getColorCount())
        .multiply(new BigDecimal("5.0"));

    // 面料费
    BigDecimal fabricFee = getFabricPrice(detail.getFabricType())
        .multiply(detail.getWidth())
        .multiply(detail.getHeight());

    // 线材费
    BigDecimal threadFee = getThreadPrice(detail.getThreadType())
        .multiply(new BigDecimal(detail.getColorCount()));

    // 总价
    BigDecimal total = basePrice
        .add(stitchFee)
        .add(colorFee)
        .add(fabricFee)
        .add(threadFee);

    // 加急加价
    if (detail.getIsUrgent()) {
        total = total.multiply(detail.getUrgentFactor());
    }

    return total;
}
```

#### 2. 分布式锁（防止重复下单）

```java
@Service
public class OrderService {

    @Autowired
    private RedissonClient redissonClient;

    public void createOrder(OrderDTO dto) {
        String lockKey = "order:create:" + dto.getUserId();
        RLock lock = redissonClient.getLock(lockKey);

        try {
            // 尝试获取锁，最多等待10秒，锁自动释放时间30秒
            if (lock.tryLock(10, 30, TimeUnit.SECONDS)) {
                // 创建订单逻辑
                doCreateOrder(dto);
            } else {
                throw new BusinessException("操作频繁，请稍后再试");
            }
        } catch (InterruptedException e) {
            Thread.currentThread().interrupt();
            throw new BusinessException("创建订单失败");
        } finally {
            if (lock.isHeldByCurrentThread()) {
                lock.unlock();
            }
        }
    }
}
```

        return Result.error(e.getCode(), e.getMessage());
